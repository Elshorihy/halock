# HALOCK Bridge for Android

تطبيق أندرويد أولي يعمل كوسيط محلي لراوتر Huawei EchoLife DN8245V-56.

## الاستخدام
1. افتح التطبيق على جهاز Android المتصل بنفس شبكة Wi-Fi المنزلية.
2. اضغط فتح الراوتر وسجّل الدخول داخل صفحة الراوتر.
3. انتقل داخل صفحة الراوتر إلى Parental Control / Website Filter.
4. اضغط فحص الأجهزة، ثم اختر جهازًا واحدًا بالاسم وعنوان MAC.
5. أدخل النطاق واضغط الحظر، ثم راجع قائمة الحظر في الراوتر بنفسك.

## الحالة والقيود
- إصدار تجريبي غير مختبر على الراوتر الحقيقي.
- لا يرسل بيانات تسجيل الدخول إلى خادم HALOCK؛ تسجيل الدخول يتم داخل WebView إلى الراوتر المحلي.
- لا يتم تجاوز تحذير شهادة HTTPS تلقائيًا؛ يظهر طلب موافقة عند وجود شهادة محلية غير موثوقة.
- يعتمد على معالجات JavaScript الخاصة بواجهة الراوتر وقد تختلف حسب إصدار البرنامج الثابت.
- ظهور رسالة نجاح يعني استدعاء معالج الواجهة فقط، وليس تأكيد حفظ القاعدة.
- قد يكون قالب Parental Control المستخدم مشتركًا؛ لا تفترض أن القاعدة معزولة عن بقية الأجهزة حتى تتحقق يدويًا.

## بناء APK
يفتح مجلد android-bridge في Android Studio باستخدام JDK 17 و Android SDK 35، أو استخدم GitHub Actions لتنزيل APK التجريبي بعد نجاح البناء.
